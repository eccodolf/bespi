# Бэспи

Бэспи — деловая и озорная чайка Банка Санкт-Петербург, с синими крыльями и красным галстуком. Анимированный питомец для ChatGPT Work.

## Установка в Codex / ChatGPT Work

1. Войдите в ChatGPT под учётной записью, в которой хотите использовать питомца.
2. Откройте [ссылку на Бэспи](https://chatgpt.com/s/sharepet_6aee2057f3ac8191bef86a4451bda13a) и добавьте питомца в свою коллекцию.
3. В режиме Work выберите Бэспи в настройках питомцев. При необходимости попросите Codex: «Выбери питомца Бэспи».

Ссылка создаёт вашу собственную копию питомца. Доступность питомцев зависит от приложения и учётной записи. Это питомец ChatGPT Work; установка как плагина или локального расширения Codex не требуется.

## Файлы
